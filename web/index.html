⚡ Clash SpeedBench · v1.0.1

Clash Verge Rev / Mihomo 节点的本地综合测速面板：延迟 + 真实带宽 + 多源 IP Intelligence + 综合评分，一键切换最优节点。

两阶段测速原理

  • Phase 1 · 并发粗筛：对所有候选节点并发探测连通性、延迟、抖动与建连耗时，快速排除不通/龟速节点。
  • Phase 2 · 串行精测：只对延迟最优的 Top-N 连通节点逐个做真实下载测速（curl 经 mixed-port），得单流中位/最佳带宽，可选 4 路并发流测峰值；样本大小随带宽自适应。
  • IP Intelligence：按出口 IP 去重后可选查询 IPinfo、IPQS、Scamalytics；分类与 IP Grade 是启发式证据汇总，不等同“真住宅”或厂商官方评分。
  • 环境泄漏检测：WebRTC/DNS 检测当前浏览器与 Clash/TUN 环境，不属于节点固有属性；DNS 页面采用 Guided Audit，不读取系统 DNS 后宣称安全。

安全说明

  • 面板只绑定 127.0.0.1，不对外暴露；零第三方依赖，纯 Python 标准库 + 原生前端。
  • 每次启动生成随机写操作令牌注入本页 <meta>，所有 POST 需携带令牌并通过 Host / Origin 校验，防跨站写请求（CSRF / DNS rebinding）。
  • 前端无任何 inline 事件属性与第三方脚本，节点名等动态文本一律转义后经 data-* 传递，杜绝注入。
