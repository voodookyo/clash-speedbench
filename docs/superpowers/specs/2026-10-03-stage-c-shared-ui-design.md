# 阶段 C：任务导向共享界面

日期：2026-10-03。状态：规格已确认，等待阶段 A/B 接口。依赖：A 目录/身份，B 模式/事件。

## 产品目标

普通用户无需正则表达式、MB 与终端即可完成选择订阅、测试推荐、查看证据和切换节点。浏览器和桌面使用同一份界面与业务逻辑，保留无构建源码 Web 入口。

不要求迁移为 React 或重写全部页面。将当前 app.js 的目录、任务、渲染、历史、泄漏与设置按边界逐步拆分；如果增加前端工具链，仅用于构建/测试，交付静态资源必须可由标准库后端服务。

## 页面结构

主导航保留概览/节点、订阅、历史、环境泄漏、设置，新增任务中心。关于与诊断放次级入口，不让供应商设置占据首页。

首页按顺序呈现：

1. Verge 连接状态、当前节点、当前运行模式/是否使用独立 worker。
2. 来源选择（全部已加载/具体订阅/收藏/手动选节点），已保存未加载项不可直接测。
3. 目标（日常/下载/IP）、模式（快速/标准/深度/IP 专项），显示预计覆盖和流量。
4. 开始按钮与高级设置折叠。自动切换默认关闭。
5. 正在运行的阶段、完成数、真实流量、预计剩余与取消；日志默认收起。
6. 已完成的增量结果与“已测范围内推荐”；不要任务结束前隐藏全部结果。

结果表默认保留节点、延迟、带宽、Network、IP Grade、IP 类型、风险；来源在分组/副标题明确呈现，不塞入所有字段。高级指标与供应商证据放详情。

## 交互与状态

- 每个节点以 node_id 为交互标识，runtime_name 只显示/经后端解析用于切换。
- 来源未知、多来源、未加载、历史来源未知分别呈现，不用空列隐藏数据缺陷。
- 选择只影响新任务，不悄悄隐藏已测记录；清晰显示结果所属轮次与范围。
- 每项指标独立 pending/success/failed/not_requested；N/A 说明原因。
- 正在 enrichment 的节点不假显示“clean”；Network 与 IP 等级更新时间分开。
- 各 Profile 使用既有规则，但下载推荐需实际带宽；显示有限覆盖声明。
- 当前节点、推荐、收藏、测量失败不是同一类标签。
- 模式回退准确提示：独立 worker 不改用户节点；串行回退将切 GLOBAL 时明确通知并要求新 UI 用户确认，不能沿用 --yes 静默回退。
- 确认切换前显示目标节点/订阅和涉及策略组；映射过期提示刷新，不随机映射。
- 刷新可续接活跃任务，后台/隐藏页面不重复启动轮询或任务。
- 任务取消后已完成结果保留，清理状态未结束前不冒充已退出。

## 历史、订阅与偏好

订阅页区分实时目录和历史汇总，按 subscription_id 查询；多来源统计避免重复计数而未说明口径。展示 probe 可用率、带宽成功率、覆盖率与订阅名变更。

历史页展示模式、范围、耗时、流量、partial 状态与指标覆盖；旧记录缺字段显示未知，不伪造任务耗时。旧名称查询与新 ID 查询都能回放，旧记录不自动归到当前来源。

将收藏从 name 迁移到 node_id；旧收藏仅当当前名字可唯一映射时转换，其余保留“待确认收藏”。偏好（主题、过滤、模式）可本地保存，认证凭据永不进入 localStorage。

## 视觉与可访问性

使用清晰的间距、字号层级、有限语义色和一致控件，支持浅色/深色与系统主题。优先桌面常见窗口宽度和窄窗口，长节点名不撑破布局。

表格支持键盘操作、可见 focus、可读 label、状态提示及适当 aria-live；风险不能仅靠红绿颜色表达。错误提供可执行下一步，而不是只弹“请求失败”。没有真实数据的空状态明确引导选择来源或开始任务。

不在功能测试前以截图好看作为验收，不依赖图片背景、远程字体或不必要的外部资源。

## 环境泄漏与设置

泄漏页顶部固定说明“当前客户端环境，不是节点固有属性”。桌面内嵌检测标为 WebView 环境；提供在系统浏览器打开当前审计页面的入口，二者结果不得混用为同一环境。

WebRTC 不支持或限制导致无法确认，DNS 继续 Guided，不能因为客户端新 UI 就改变既有科学边界。人工 DNS 记录保留来源/时间/环境，不标成自动 observer 结果。

设置显示连接、目录解析、provider 配置状态；Key 仅提交 localhost 后端内存，不回显。控制器自动发现与第三方 API 凭据分开解释，避免再次误导用户认为基础测速需付费 Key。

## 验收

1. 从空安装到来源选择、快速推荐、展开证据、手动切换的完整操作。
2. 两个同名节点、多来源、来源未知、订阅改名与旧收藏待确认。
3. 无 Key、断开 Verge、超时、无节点、全部失败、部分完成、串行回退确认。
4. 增量更新不会丢选择/展开位置，刷新不会重复任务，终态与日志一致。
5. 历史、趋势、IP 变更、信誉、泄漏页和设置保持可用。
6. 节点名/订阅名含 HTML/引号/Unicode/emoji 不执行代码且 Windows 控制台兼容。
7. 键盘、浅/深主题、窄窗口、长名称实际渲染验证。
8. 浏览器和桌面加载同一静态资源，测试记录同时包含实际操作与截图证据。
